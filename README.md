### Heartbeat Monitor

A small network monitor. Add IP addresses or hostnames and each one is pinged every 5 seconds:

- a green dot when it answers, a flashing red dot when it doesn't
- host name and IP address (looked up like `nslookup`)
- response time, plus a bar chart of the last 10 pings
- hop count to each address (like `traceroute`); click it to see every hop
- **Scan network…** finds the devices on your network so you can add them in one go

It is a single `.exe`: download it and double-click. Nothing is installed, and your list of addresses is saved in `%APPDATA%\HeartbeatMonitor\`.

### Parlor Games

Blackjack, roulette, craps and mahjong solitaire, played with pretend chips. No real money, no ads, no account. You start with 10,000 chips.

It is a single `.exe`: download it and double-click. Nothing is installed, and your chips are saved in `%APPDATA%\Godot\app_userdata\Parlor Games\`.

## First launch warning

These apps aren't signed by a registered publisher yet, so Windows shows **"Windows protected your PC"** the first time. Click **More info**, then **Run anyway**. Some antivirus tools also flag apps packaged this way.
